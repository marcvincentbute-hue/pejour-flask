# Shared visual theme

Source: the student's supplied CoachPro dashboard reference. Its color language is adapted to Pejour, not its sports content or branding.

| Token | Value / purpose |
| --- | --- |
| Main text | `#183c33`, dark green |
| Secondary text | `#58736d` |
| Teal action | `#087f8c` |
| Teal hover | `#066573` |
| Mint | `#e7f2ed` |
| Lavender | `#e2dff3` |
| Glass surfaces | Translucent mint-white, light border, soft shadow |
| Error | `#a52b42`, text under the affected field |

All routes extend the same base template and load `pejour/static/css/app.css`. Cards use rounded corners, subtle shadows and restrained pastel variation. Login, registration, email verification, recovery, journal, privacy, errors and admin monitoring share the palette. No sports logos, third-party avatars or reference screenshot assets are embedded. The desktop sidebar becomes visible navigation links on mobile. Tables scroll within their cards rather than widening the page. Reduced-motion preference disables transitions.
